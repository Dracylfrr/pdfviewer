# Privacy

PDF Viewer stores file paths, notes, text indexes, reading state, and backups locally. App preferences live in the WebView profile. Page thumbnails are cached on disk and can be cleared in Settings.

The application has no account, analytics, advertising, or telemetry. PDF Viewer checks its GitHub releases on startup by default and when you request a manual check. You can turn off the startup check in Settings. Your PDFs, notes, and searches stay on your device.

Metadata backups can include filenames, folder paths, annotations, and extracted text. Safeguard them as you would your library. Back up original PDFs separately.
