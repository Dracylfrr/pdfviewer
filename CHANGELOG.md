# Changelog

## 0.3.2 development preview

- Print all PDF pages by default, with an editable range and cancelable preparation.

## 0.3.1 development preview

- Clear the recent PDFs list while keeping reading progress and annotations.
- Keep background update checks and remove the GitHub Releases button.

## 0.3.0 development preview

- Add Home with recent PDFs, first-page thumbnails, and resume actions.
- Check PDF Viewer GitHub releases on startup and link to the release downloads.
- Print a page range from the open PDF.

## 0.2.0 development preview

- Open PDFs with one click in Columns, Tree, and Graph.
- Resize the library, its individual columns, and the annotations pane by dragging a divider or using its keyboard controls.
- Adjust reading scale with a slider, Fit width, or Fit page.
- Follow the color-coded and numbered folder path in Graph. File and folder icons use gray artwork.

## 0.1.0 development preview

- Browse multiple physical PDF libraries in Columns, Tree, and scoped Graph views.
- Read PDFs with continuous and single-page layouts, text search, thumbnails, outline, and saved reading settings.
- Store annotations, folder notes, bookmarks, tags, and related-document links in SQLite.
- Export annotation JSON and Markdown, import annotation JSON, and back up or restore metadata.
- Provide optional library PDF text indexing and an installer for Windows x64.
- Default to Pastel Blue and offer independent paper themes in the reader.
