# Roadmap

## Before 1.0

- Verify signed updates end to end against the project's GitHub release feed.
- Test the Windows installer on a clean machine and reproduce the offline, restart, and recovery checks in the implementation spec.
- Profile large and image-heavy PDFs, scrolling, idle CPU, and total process-tree memory.
- Exercise missing-file relinking on more fixtures, improve duplicate matching, and verify backup restoration after interrupted writes.
- Add range-based PDF loading and refine continuous scrolling for mixed-size documents.
- Finish the keyboard and accessibility coverage in the specification.
